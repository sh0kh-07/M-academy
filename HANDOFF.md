## Стиль, который хочет пользователь (важно)

- **Серьёзно, кинематографично, сдержанно.** Первую версию (яркие флаги на флагштоках, золотые искры) назвал «детской».
- Флаги в hero — **приглушённый фон**, переходы между планами **через затемнение в чёрное**, «как в кино».
- Флаг должен **заполнять весь кадр** — без чёрных краёв.
- Любит **3D, анимации, эффект «вау»**, но сайт **не должен лагать**.
- **Перед крупной переделкой сохраняй текущую версию** git-тегом (`v1`…`v6`), чтобы можно было вернуться.
- Пользователь пишет по-русски (иногда вставки на узбекском кириллицей). Отвечать по-русски.

## Стек

- **React 19 + React Router 7**, сборка **Vite 8** (`@vitejs/plugin-react`)
- **three.js** — флаги в hero, 3D-логотип, глобус
- **GSAP** (+ ScrollTrigger только на странице курсов)
- **Lenis** — плавный скролл
- Без Tailwind, без бэкенда. Чистый CSS в `src/styles.css`.

```bash
npm run dev      # http://localhost:5173
npm run build    # → dist/
npm run preview  # проверка сборки
```

Хостингу нужен **SPA-fallback** (все пути → `index.html`), иначе прямые ссылки вроде `/news/...` дадут 404.

## Hero (главное, над чем долго работали)

`src/lib/hero.js`: три плана по кругу, каждый ~7.4 с, между ними затемнение:
1. флаг Узбекистана во весь кадр,
2. флаг академии с логотипом,
3. «оба вместе» — одно полотно, разделённое **золотым швом** по диагонали (на телефоне шов горизонтальный).

Настройки в начале файла: `SPEED` (скорость ткани, сейчас 1.5), `TIMING` (длительности), `BLEED` (запас полотна за краями кадра), `GAIN` (яркость каждого флага).
На портретных экранах флаги сверху, текст снизу (`LAYOUTS` в hero.js ↔ `@media (max-aspect-ratio: 1/1)` в CSS — держать синхронно).

## Важные технические решения (не ломать)

- Состояние анимаций хранится в **`data-*` атрибутах** (`data-in`, `data-tilting`, `data-active`…), а не в классах — React перетирает `className`.
- Каждая WebGL-сцена получает **собственный `<canvas>`** через `useScene()` в `Scenes.jsx` (иначе после hot reload контекст теряется → белый квадрат).
- Сцены рендерятся только когда видны (`IntersectionObserver`), pixel ratio ≤ 1.5, у флагов адаптивное разрешение.
- `LearningPath` пересчитывает ScrollTrigger через `ResizeObserver`, когда страница выше меняет высоту (баг «скролл вправо не работает» был из-за этого).
- `scrollToTop({immediate:true})` прыгает нативно и делает `lenis.reset()` — `lenis.scrollTo(0, {immediate})` ненадёжен.
- Без `backdrop-filter` / `mix-blend-mode` / анимированного blur — из-за них были лаги.
- В dev доступны `window.__maScene.debugFrame(shot, sec, time)` и `window.__gsap` (для проверки кадров); в продакшен-сборку не попадают.

## Админ-панель (`/admin`)

Бэкенд: NestJS, `https://dev.m-academy.uz/api` (Swagger `/api/docs` закрыт basic-auth; разделы пользователь присылает текстом).
Ошибки приходят как `{ statusCode, error, message }`, `message` — строка или массив (валидация).

- `src/admin/` — отдельный бандл, грузится лениво только на `/admin` (`App.jsx`). Стили `admin.css`, всё под `.adm`.
- `api.js` — клиент: `api(path, opts)`, `login`, `logout`, `me`, `changePassword`. Токены в `localStorage` (`ma-admin-session`).
  **Refresh-токен одноразовый**: повторная отправка старого = «кража» → сервер убивает все сессии. Поэтому обновление
  токена сериализовано (общий промис + Web Locks между вкладками) и всегда берёт свежую пару из хранилища. Не ломать.
- `auth.jsx` — `useAuth()`: `status` (`loading|authed|guest|error`), `user`, `ended` (почему вышли). Синхронизация между вкладками.
- Страницы: `/admin/login`, `/admin` (главная: аккаунт + счётчики новостей/курсов из `/api/news`, `/api/courses`), `/admin/profile` (данные + смена пароля).
- Тексты админки — `src/admin/dict.js` (uz/ru/en), язык общий с сайтом.
- В админке Lenis выключается (`stopSmoothScroll`), на выходе включается обратно; добавляется `meta robots noindex`.
- Запросы идут на `/api` того же домена: Vite проксирует его в dev и preview (`vite.config.js`, `API_TARGET`).
  CORS бэкенда пропускает только `http://localhost:5173`. На проде: nginx проксирует `/api`, либо `VITE_API_URL` + домен в CORS бэкенда (см. `.env.example`).
- Новый раздел: страница в `src/admin/pages`, `<Route>` в `AdminApp.jsx`, пункт в `NAV` в `AdminLayout.jsx` («Новости» пока серые «скоро»).

  создание/редактирование (`pages/CourseEdit.jsx`: тексты uz/ru/en во вкладках, **только фото** — справа над настройками, загружается сразу через

  с правильным склонением и описанием). На «Академии» — учителя из API; **пока их 0, остаются 4 заглушки «Namuna»**. На странице курса — учителя курса.
- **Регистрация** (`pages/Register.jsx`) шлёт заявку в `POST /api/leads`: `full_name` (только буквы), `age` (3–100), `phone` (+998…),
  `region` (из `GET /api/regions`), `course_id` — только у курса из API. На шаге 2 добавлены «Возраст» и «Регион». 429 → «слишком много
  заявок». `CONFIG.formEndpoint` больше нет.
- **Посещения**: `Layout.jsx` при смене страницы шлёт `POST /api/visits { path }` — **только в боевой сборке** (`import.meta.env.PROD`).
- `useReveal` теперь подхватывает `[data-reveal]`, появившиеся позже (данные из API), через MutationObserver.
- Пример из Swagger `superadmin / Admin12345` на dev-сервере **не подходит**. 5 неверных паролей подряд блокируют аккаунт на 15 мин, 10 попыток в минуту с IP — блок IP на 5 мин.
